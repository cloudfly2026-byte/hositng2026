# Hosting 2026 — Cloud Platform & Microservices Studio

Plataforma SaaS multi-tenant de hosting y Cloud orientada a la gestión sencilla (*Cuenta → Proyecto → Servicio*), con soporte para:
- **Shared Cloud** (cargas distribuidas entre VPS del pool)
- **Dedicated Cloud** (VPS exclusivo por cliente)
- **Motores**: HestiaCP (PHP/WordPress) y Dokploy + Docker (Node.js, Python, Java, .NET)
- **Metodología**: TDD estricto (*Red → Green → Refactor*)

Consulta [AGENTS.md](./AGENTS.md) para más detalles sobre la arquitectura, diseño y guías de desarrollo.
